## 🔬 Research & Academic Work

My research interests include privacy-preserving machine learning, explainable AI, medical image segmentation, and Bengali natural language processing.

- **Brain Tumor Segmentation:** Federated transfer learning for MRI-based segmentation using CNN-based U-Net and Transformer-based U-Net architectures.
- **Bangla Fake News Detection:** Hybrid deep learning and transformer-based approaches using BERT, XLM-RoBERTa, and LIME.
- **Explainable Bengali Fake News Detection:** Category-aware multi-task learning using BanglaBERT, BiLSTM, attention, LIME, and SHAP.
- **Pancreatic Malignancy Detection:** Federated learning with ANN models and FedAvg aggregation.
- **Leukemia Stage Classification:** Ensemble deep learning using ResNet18 and VGG16 with explainable AI.
- **Colorectal Cancer Detection:** Privacy-preserving federated training using deep learning and FedAvg.
